# 🏋️‍♂️ NR ACADEMIA — Interface Web

> Website institucional e informativo desenvolvido para a NR Academia, apresentando planos, modalidades, estrutura e canais de contato.

## 🚀 Sobre o Projeto
O site da **NR Academia** foi criado para oferecer uma experiência moderna, fluida e responsiva aos alunos e visitantes. A página reúne informações sobre modalidades de treino, horários de funcionamento, diferenciais da academia, tabela de planos e informações de contato.

## 🤖 Desenvolvimento Generativo (Prompt Engineering)
Este projeto foi **construído 100% via Inteligência Artificial**. 
* **Função do Desenvolvedor:** Atuei como Prompt Engineer, definindo a arquitetura de informação, a identidade visual, a estrutura das seções e as regras de layout.
* **Geração de Código:** Toda a marcação e o estilo da aplicação foram gerados por IA a partir de prompts sequenciais de direcionamento e refinamento.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação semântica gerada por IA.
* **CSS3:** Estilização, layout responsivo (Flexbox/Grid) e efeitos visuais criados por IA.
* **Engenharia de Prompt:** Direcionamento e arquitetura das soluções visuais e técnicas.
